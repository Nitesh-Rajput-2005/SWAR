\# SWAR 🎵



SWAR is a full-stack music streaming web application that allows users to create accounts, verify their email using OTP authentication, browse songs, play music, and create playlists.



\## Features



\- User signup and login

\- Email OTP verification

\- JWT-based authentication

\- Music player

\- Song browsing

\- Playlist creation

\- Add songs to playlists

\- MongoDB database

\- Responsive music player interface



\## Tech Stack



\### Frontend

\- HTML

\- CSS

\- JavaScript



\### Backend

\- Node.js

\- Express.js

\- MongoDB

\- Mongoose

\- JWT

\- Nodemailer

\- Joi

\- bcrypt
